# Image slots

Every image on the site is placeholder art (`.svg`) generated by
`scripts/gen-placeholders.mjs`. None of it is real restaurant photography —
each file is a labeled, abstract stand-in so the owner can swap in real
photos without touching any component code.

To replace a photo: drop a real file into this folder (JPEG or PNG
recommended) at the same target dimensions, then update its `src` in
`content/images.ts` to point at the new filename. That's the only file that
needs to change — every page reads image paths from there.

## Conventions

- Filenames are kebab-case, descriptive, no numbers-only names.
- Aspect ratios above are load-bearing — components size their containers
  around them. If a replacement photo has a different ratio, either crop it
  to match or update the `width`/`height` in `content/images.ts` and re-check
  the layout at 375px, 768px, and 1440px.
- Alt text lives next to each slot in `content/images.ts`, not in components.
  Update it to describe the real photo when you swap one in.
- Do not commit real customer or Yelp/Google/Instagram photography without
  the rights to use it commercially.
